# Design System — 21st.dev inspired

UI patterns adapted from [21st.dev](https://21st.dev) community components (vanilla HTML/CSS port):

| Section | 21st reference | Author |
|---------|----------------|--------|
| Hero + golden spiral | [Hero Golden Spiral](https://21st.dev/@ncdai/components/hero-01) | Chánh Đại |
| Aurora background | [Background Gradient Glow](https://21st.dev/@meghtrix/components/background-gradient-glow) | meghtrix |
| Glass navbar | [Hero Section 9](https://21st.dev/@meschacirung/components/hero-section-9) | Méschac Irung / Tailark |
| Service cards | [Modern Hero](https://21st.dev/@shadcnblockscom/components/modern-hero) | Shadcnblocks |
| Trust marquee | [Testimonials Marquee](https://21st.dev/@shadcnspace/components/marquee-01) | ShadcnSpace |

## Stack

- Vanilla HTML / CSS / JS (no React)
- Fonts: Instrument Serif + Plus Jakarta Sans
- Colors: navy `#0f1629` + gold `#c9a227`

## 21st CLI (optional)

```bash
npx @21st-dev/cli login
npx @21st-dev/cli search "hero immigration" --json
```

Set `TWENTYFIRST_TOKEN` or API key from https://21st.dev/mcp for direct component installs.
